# Lesson 2.11. Add instances: sequence, quantity, condition and physical status changes

Features: [F01](../features/01-catalog-management.md#instances)
Previous: [2.10](2.10-inventory-code-value-object.md) · Next: 2.12 QR labels with QRCoder (SVG, label sheet), lookup by scanned code

## Summary

We add the `SetInstance` aggregate, one physical copy of a set. An admin adds one or more instances to a set with `POST /catalog/sets/{id}/instances`. Each instance gets an inventory code from the PostgreSQL sequence `inventory_code_seq`, and the admin can change its condition and physical status with `PUT /catalog/instances/{id}`. At the end the Domain and Api tests for instances are green. Labels, events, and notes are not part of this lesson.

## The problem

Catalog knows sets, but not the copies the shop owns. [Catalog management](../features/01-catalog-management.md#instances) defines an instance like this:

> An instance is one physical copy of a set: inventory code, condition (`New`, `Good`, `Worn`), physical status (`Available`, `InMaintenance`, `Retired`, `Lost`), notes.

The feature doc also sets these rules for generating the code:

> Take the next number `n` from the PostgreSQL sequence `inventory_code_seq` (one query for all instances when `quantity` > 1).

> The inventory code is generated by Catalog. It is unique, never reused, and never changes. The admin does not type it.

Lesson 2.10 gave us `InventoryCode.FromSequence(n)`, which turns a number into a code. This lesson supplies the number. Two endpoints come from the endpoint table in the same doc:

| Method | Route | Policy | Purpose |
|--------|-------|--------|---------|
| POST | `/catalog/sets/{id}/instances` | `AdminOnly` | Add one or more instances (`quantity`), returns ids and inventory codes |
| PUT | `/catalog/instances/{id}` | `AdminOnly` | Change condition or status |

The concepts we introduce:

- **An aggregate with state changes through methods.** `SetInstance` has private setters. `ChangeCondition` and `ChangeStatus` are the only ways to change its state, as [CLAUDE.md](../../CLAUDE.md) requires. The aggregate refers to its set by `SetId`, and it does not hold a reference to `LegoSet`.
- **A port for the sequence.** The domain depends on the interface `IInventoryCodeSequence`. The Api project implements it with a PostgreSQL query. The sequence belongs to the database, so the domain does not read it.
- **One query for many numbers.** `SELECT nextval(...) FROM generate_series(1, n)` returns `n` numbers in one round trip.
- **String constants for fixed values.** `Condition` and `Status` are strings, and the allowed values are `const` strings in two static classes. JSON and the database get readable text such as `"Good"` and `"Available"` with no converter.

Adding instances creates new `SetInstance` rows. It does not change the `LegoSet` aggregate, so the handler changes only one aggregate.

What this lesson does not do:

- It does not print labels. That is lesson 2.12, which also adds the `label` links.
- It does not publish `InstanceAdded` or `InstanceStatusChanged`. The outbox comes in a later lesson.
- It does not add `Notes` or the scan lookup by code.
- It does not add the rules for inspection or lost sets. Those belong to F09 and F10.

using BrickShare.Catalog.Domain;

using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

namespace BrickShare.Catalog.Api.Infrastructure.Persistence;

public sealed class SetInstanceConfiguration : IEntityTypeConfiguration<SetInstance>
{
    public void Configure(EntityTypeBuilder<SetInstance> builder)
    {
        builder.ToTable("set_instances");

        builder.HasKey(instance => instance.Id);

        builder.Property(instance => instance.Id)
            .ValueGeneratedNever()
            .HasColumnName("id");

        builder.Property(instance => instance.SetId)
            .HasColumnName("set_id");

        builder.HasOne<LegoSet>()
            .WithMany()
            .HasForeignKey(instance => instance.SetId);

        builder.Property(instance => instance.InventoryCode)
            .HasConversion(code => code.Value, value => InventoryCode.Parse(value).Value)
            .HasColumnName("inventory_code")
            .HasMaxLength(7);

        builder.HasIndex(instance => instance.InventoryCode)
            .IsUnique();

        builder.Property(instance => instance.Condition)
            .HasColumnName("condition")
            .HasMaxLength(10);

        builder.Property(instance => instance.Status)
            .HasColumnName("status")
            .HasMaxLength(20);

        builder.Ignore(instance => instance.DomainEvents);
    }
}
```

The stored code is already valid and normalized, so `Parse` only returns the value. `HasMaxLength(7)` fits both code lengths that `InventoryCode` accepts.

using System.Collections.Generic;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Domain;

using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Infrastructure.Persistence;

public sealed class PostgresInventoryCodeSequence(CatalogDbContext dbContext) : IInventoryCodeSequence
{
    public async Task<IReadOnlyList<long>> NextValuesAsync(int count, CancellationToken cancellationToken) =>
        await dbContext.Database
            .SqlQuery<long>($"SELECT nextval('inventory_code_seq') FROM generate_series(1, {count})")
            .ToListAsync(cancellationToken);
}
```

The query calls `nextval` once for each row that `generate_series` produces. The count is a query parameter, so the SQL text does not change with the quantity.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Domain;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;

namespace BrickShare.Catalog.Api.Features.Instances.Add;

public static class AddInstances
{
    public static void MapAddInstances(this RouteGroupBuilder sets) =>
        sets.MapPost("/{id:guid}/instances", Handle);

    private static async Task<Results<Created<IReadOnlyList<InstanceResponse>>, ProblemHttpResult>> Handle(
        Guid id,
        AddInstancesRequest request,
        CatalogDbContext dbContext,
        IInventoryCodeSequence codeSequence,
        CancellationToken cancellationToken)
    {
        var numbers = await codeSequence.NextValuesAsync(request.Quantity, cancellationToken);

        var instances = numbers
            .Select(number => new SetInstance(Guid.CreateVersion7(), id, InventoryCode.FromSequence(number), request.Condition))
            .ToList();

        dbContext.SetInstances.AddRange(instances);
        await dbContext.SaveChangesAsync(cancellationToken);

        IReadOnlyList<InstanceResponse> responses = instances.Select(InstanceResponse.From).ToList();

        return TypedResults.Created($"/catalog/sets/{id}/instances", responses);
    }
}
```

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;

namespace BrickShare.Catalog.Api.Features.Instances.Update;

public static class UpdateInstance
{
    public static void MapUpdateInstance(this RouteGroupBuilder instances) =>
        instances.MapPut("/{id:guid}", Handle);

    private static async Task<Results<Ok<InstanceResponse>, ProblemHttpResult>> Handle(
        Guid id,
        UpdateInstanceRequest request,
        CatalogDbContext dbContext,
        CancellationToken cancellationToken)
    {
        var instance = await dbContext.SetInstances.FindAsync([id], cancellationToken);

        if (instance is null)
        {
            return InstanceProblems.NotFound(id);
        }

        instance.ChangeCondition(request.Condition);
        instance.ChangeStatus(request.Status);
        await dbContext.SaveChangesAsync(cancellationToken);

        return TypedResults.Ok(InstanceResponse.From(instance));
    }
}
```
