# Lesson 2.12. QR labels with QRCoder (SVG, label sheet), lookup by scanned code

Features: [F01](../features/01-catalog-management.md#inventory-code-and-qr-label)
Previous: [2.11](2.11-add-instances.md) · Next: 2.13 Set images: SAS upload URLs with Azurite

## Summary

We print the labels that go on the boxes. `GET /catalog/instances/{id}/label` returns one SVG label for an instance, and `POST /catalog/instances/labels` returns one SVG sheet with a label for each instance in the request. Each label holds a QR code with the inventory code, the code as text, the set name, and the LEGO set number. `GET /catalog/instances/by-code/{inventoryCode}` resolves a scanned code to the instance and its set, for staff. At the end the Api tests for labels and lookup are green. The Domain project does not change.

## The problem

The admin can add instances, and each instance now has an inventory code, but nothing puts the code on the box. [Catalog management](../features/01-catalog-management.md#inventory-code-and-qr-label) sets these rules for the label:

> The QR code contains **only the inventory code** as plain text, for example `W9X-25W`. No URL and no internal id.

> Label format: SVG, 50 × 30 mm, ready for a label printer or a normal printer.

> Adding several instances returns all their labels in one printable sheet.

> The code alone gives no access: every lookup needs a signed-in staff account.

The same doc asks for error correction level H, so the QR code still scans when part of it is damaged. It also asks for a lookup that resolves a scanned code to the instance, its set, and its current physical status. Three endpoints come from the endpoint table:

| Method | Route | Policy | Purpose |
|--------|-------|--------|---------|
| GET | `/catalog/instances/{id}/label` | `AdminOnly` | Label for one instance (SVG), also for reprints |
| POST | `/catalog/instances/labels` | `AdminOnly` | Printable sheet with labels for several instances |
| GET | `/catalog/instances/by-code/{inventoryCode}` | `EmployeeOrAdmin` | Resolve a scanned code: instance, set, condition, physical status |

This lesson also adds the `labelUrl` to the add response. Lesson 2.11 left it out on purpose.

The concepts we introduce:

- **QRCoder renders the QR code as SVG.** `QRCoder` is an MIT library that encodes the text and draws the modules. We pass the error correction level `H` and an SVG sizing mode. The code is not stored. Labels are rendered on every request, so a reprint is always the same.
- **The label is a template in code.** `InstanceLabelRenderer` builds the SVG text. It does no I/O, so it needs no port. The ports from [Architecture 7.1](../Architecture.md#71-domain-driven-design) cover external systems, and a local library does not count.
- **A read model for the joined data.** A label needs the instance and its set. `InstanceView` is one query that joins the two tables. It is a read-side projection, so it is not domain logic.
- **One endpoint group per policy.** An endpoint inherits the policy of its group, and it cannot add a second one. The admin routes sit in the `AdminOnly` group. The lookup needs its own group with `EmployeeOrAdmin`, because staff must reach it and the admin group would block them.

This lesson has no new domain rule. The Domain tests from lesson 2.11 stay as they are, and every new test is an integration test.

What this lesson does not do:

- It does not print labels on a printer. It produces the SVG, and the printer is out of scope.
- It does not paginate a long sheet. A sheet with many rows grows taller instead of splitting into A4 pages.
- It does not add the reservation lookup `GET /reservations/by-instance/{code}/active`. That comes with the Reservation Service.

```csharp
using System;
using System.Linq;
using System.Linq.Expressions;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Domain;

namespace BrickShare.Catalog.Api.Features.Instances;

public sealed record InstanceView(
    Guid Id,
    InventoryCode InventoryCode,
    string Condition,
    string Status,
    Guid SetId,
    string SetName,
    LegoSetNumber LegoSetNumber)
{
    public static IQueryable<InstanceView> Query(
        CatalogDbContext dbContext,
        Expression<Func<SetInstance, bool>> filter) =>
        dbContext.SetInstances.Where(filter).Join(
            dbContext.LegoSets,
            instance => instance.SetId,
            legoSet => legoSet.Id,
            (instance, legoSet) => new InstanceView(
                instance.Id,
                instance.InventoryCode,
                instance.Condition,
                instance.Status,
                legoSet.Id,
                legoSet.Name,
                legoSet.LegoSetNumber));
}
```

`InstanceView` has no mapping of its own. EF Core projects into it with `new InstanceView(...)`. EF Core cannot translate a filter on a property of the constructed view, so the query takes the filter on the instance and applies it before the join. The value converters in the existing mappings apply to the two value objects: the inventory code from lesson 2.11, and the LEGO set number from lesson 2.3.

`src/Services/Catalog/BrickShare.Catalog.Api/Features/Instances/Label/InstanceLabelRenderer.cs` (replace the template class with this content)

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Security;
using System.Text;

using QRCoder;

namespace BrickShare.Catalog.Api.Features.Instances.Label;

public static class InstanceLabelRenderer
{
    private const int LabelWidth = 50;
    private const int LabelHeight = 30;
    private const int SheetWidth = 210;
    private const int SheetColumns = 4;
    private const int SheetMargin = 5;
    private const int MaxNameLength = 14;

    public static string RenderLabel(InstanceView view) =>
        $"""<svg xmlns="http://www.w3.org/2000/svg" width="{LabelWidth}mm" height="{LabelHeight}mm" viewBox="0 0 {LabelWidth} {LabelHeight}">{LabelBody(view)}</svg>""";

    public static string RenderSheet(IReadOnlyList<InstanceView> views)
    {
        var rows = (views.Count + SheetColumns - 1) / SheetColumns;
        var height = rows * LabelHeight + 2 * SheetMargin;
        var body = new StringBuilder();

        for (var index = 0; index < views.Count; index++)
        {
            var x = SheetMargin + (index % SheetColumns) * LabelWidth;
            var y = SheetMargin + (index / SheetColumns) * LabelHeight;
            body.Append(CultureInfo.InvariantCulture, $"""<g transform="translate({x} {y})">{LabelBody(views[index])}</g>""");
        }

        return $"""<svg xmlns="http://www.w3.org/2000/svg" width="{SheetWidth}mm" height="{height}mm" viewBox="0 0 {SheetWidth} {height}">{body}</svg>""";
    }

    private static string LabelBody(InstanceView view)
    {
        var code = view.InventoryCode.ToString();

        return $"""
            {QrImage(code)}
            <text x="12" y="27" font-family="monospace" font-size="4" font-weight="bold" text-anchor="middle">{code}</text>
            <text x="26" y="10" font-family="sans-serif" font-size="3">{SecurityElement.Escape(Shorten(view.SetName))}</text>
            <text x="26" y="16" font-family="sans-serif" font-size="3">{view.LegoSetNumber.Value}</text>
            """;
    }

    private static string QrImage(string payload)
    {
        using var generator = new QRCodeGenerator();
        using var data = generator.CreateQrCode(payload, QRCodeGenerator.ECCLevel.H);
        using var qrCode = new SvgQRCode(data);

        var svg = qrCode.GetGraphic(1, "#000000", "#FFFFFF", true, SvgQRCode.SizingMode.ViewBoxAttribute);
        var href = $"data:image/svg+xml;base64,{Convert.ToBase64String(Encoding.UTF8.GetBytes(svg))}";

        return $"""<image x="2" y="2" width="20" height="20" href="{href}"/>""";
    }

    private static string Shorten(string name) =>
        name.Length <= MaxNameLength ? name : $"{name[..(MaxNameLength - 1)]}…";
}
```

The renderer works in millimetres. The `viewBox` uses the same units, so a font size of `4` means 4 mm. The QR code sits in the left 22 mm of the label, and the code is printed below it, so staff can type it when a scan fails. The set name and the LEGO set number are in the right column.

`QrImage` makes the QR code an SVG image and embeds it as a data URI. The label stays one self-contained file, and QRCoder's output does not need any change. The `ViewBoxAttribute` mode leaves the size to the `width` and `height` of the image element, so the pixel size `1` has no effect here.

The payload is `InventoryCode.ToString()`, which gives `W9X-25W`. It holds the code and nothing else, as the feature doc requires.

`Shorten` keeps long set names inside the column. The name is cut at 14 characters and ends with `…`. The feature doc does not give a length, so this lesson picks one.

`RenderSheet` is not used until step 11. It goes in now, because the renderer is one file and the sheet is one of its two outputs.

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Instances.Label;

public static class GetInstanceLabel
{
    public static void MapGetInstanceLabel(this RouteGroupBuilder instances) =>
        instances.MapGet("/{id:guid}/label", Handle);

    private static async Task<Results<ContentHttpResult, ProblemHttpResult>> Handle(
        Guid id,
        CatalogDbContext dbContext,
        CancellationToken cancellationToken)
    {
        var view = await InstanceView.Query(dbContext, instance => instance.Id == id)
            .FirstOrDefaultAsync(cancellationToken);

        if (view is null)
        {
            return InstanceProblems.NotFound(id);
        }

        return TypedResults.Content(InstanceLabelRenderer.RenderLabel(view), "image/svg+xml");
    }
}
```

```csharp
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Features.Instances.Label;
using BrickShare.Catalog.Api.Infrastructure.Persistence;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Instances.LabelSheet;

public static class CreateLabelSheet
{
    public static void MapCreateLabelSheet(this RouteGroupBuilder instances) =>
        instances.MapPost("/labels", Handle);

    private static async Task<Results<ContentHttpResult, ProblemHttpResult>> Handle(
        LabelSheetRequest request,
        CatalogDbContext dbContext,
        CancellationToken cancellationToken)
    {
        var views = await InstanceView.Query(dbContext, instance => request.InstanceIds.Contains(instance.Id))
            .ToDictionaryAsync(view => view.Id, cancellationToken);

        if (request.InstanceIds.Any(id => !views.ContainsKey(id)))
        {
            return InstanceProblems.SomeNotFound();
        }

        var labels = request.InstanceIds.Select(id => views[id]).ToList();

        return TypedResults.Content(InstanceLabelRenderer.RenderSheet(labels), "image/svg+xml");
    }
}
```

The query asks for all instances with one `WHERE id IN (...)`. The check after it compares the two lists, so a missing id cannot slip through. `SomeNotFound` goes into `InstanceProblems`, next to `NotFound`.

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Domain;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Instances.LookupByCode;

public static class LookupInstanceByCode
{
    public static void MapLookupInstanceByCode(this RouteGroupBuilder instances) =>
        instances.MapGet("/by-code/{inventoryCode}", Handle);

    private static async Task<Results<Ok<ScannedInstanceResponse>, ProblemHttpResult>> Handle(
        string inventoryCode,
        CatalogDbContext dbContext,
        CancellationToken cancellationToken)
    {
        var parsed = InventoryCode.Parse(inventoryCode);

        var view = await InstanceView.Query(dbContext, instance => instance.InventoryCode == parsed.Value)
            .FirstOrDefaultAsync(cancellationToken);

        if (view is null)
        {
            return InstanceProblems.UnknownInventoryCode(inventoryCode);
        }

        return TypedResults.Ok(ScannedInstanceResponse.From(view));
    }
}

public sealed record ScannedInstanceResponse(
    Guid Id,
    string InventoryCode,
    string Condition,
    string Status,
    Guid SetId,
    string SetName,
    string LegoSetNumber)
{
    public static ScannedInstanceResponse From(InstanceView view) => new(
        view.Id,
        view.InventoryCode.ToString(),
        view.Condition,
        view.Status,
        view.SetId,
        view.SetName,
        view.LegoSetNumber.Value);
}
```

The handler parses the code first and then compares the stored code with the parsed value. The parse step does the normalization from lesson 2.10: lowercase is accepted, and dashes and spaces are ignored. The first version does not check for a failed parse yet. Step 19 adds that check.

## Result

The Catalog Service prints labels and resolves scanned codes.

- `GET /catalog/instances/{id}/label` returns one 50 × 30 mm SVG label. It holds a QR code with the inventory code, the code as text, the set name, and the LEGO set number. It holds no instance id and no customer data. An unknown instance returns `404`.
