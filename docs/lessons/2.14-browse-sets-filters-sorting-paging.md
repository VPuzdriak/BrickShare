# Lesson 2.14. Browse sets: filters, sorting, paging, set details

Features: [F02](../features/02-catalog-browsing-and-search.md)
Previous: [2.13](2.13-set-images-sas-upload-urls.md) · Next: 2.15 Fuzzy search with `pg_trgm`

## Summary

Anonymous visitors browse the catalog. `GET /catalog/sets` returns the active sets, filtered by theme, piece count, and daily price, sorted by name, pieces, or price, and paged with `page`, `pageSize`, and a total count. `GET /catalog/sets/{id}` returns the details of one active set. At the end the Api tests for browsing and details are green. This lesson adds no domain code, because browsing is a read-side query and not a business rule.

## The problem

Catalog stores sets, but a customer cannot see them yet. Only admins reach the set endpoints. [Catalog browsing and search](../features/02-catalog-browsing-and-search.md) sets the rules for browsing:

> Only active sets (`IsActive`) are listed.

> Filters: theme, age (`AgeFrom <= age`), piece range, daily price range.

> With no search text, results sort by the chosen field (name, pieces, price, newest).

> Paging is classic `page` / `pageSize` with a total count.

Two endpoints come from the endpoint table in the same doc:

| Method | Route | Policy | Purpose |
|--------|-------|--------|---------|
| GET | `/catalog/sets?q&themeId&age&minPieces&maxPieces&minPrice&maxPrice&sort&page&pageSize` | Anonymous | Fuzzy search, filter, sort and page sets |
| GET | `/catalog/sets/{id}` | Anonymous | Set details |

This lesson builds the list and the details, without these parts:

- **Search text (`q`).** Fuzzy search is lesson 2.15.
- **Age filter and the `newest` sort.** `LegoSet` has no minimum age and no creation time yet. Adding them changes the set contract and needs a decision about existing sets, so this lesson leaves both out.
- **Availability.** The availability endpoints proxy to the Reservation Service, which comes in module 6.
- **Facets.** The theme endpoint and the facet counts come in lesson 2.16.

The feature doc does not fix these choices, so this lesson makes them:

- Sorting is ascending. The default sort is `name`.
- `page` starts at 1. `pageSize` defaults to 20 and is at most 100.
- Prices in the query use minor units, like the set API. `minPrice=1500` means 15.00 EUR.
- A deactivated set has no details. Its id returns `404`, the same as an unknown id.

Concepts this lesson introduces:

- **Browsing is a read-side query.** The handlers read through `CatalogDbContext` and return response records. No aggregate changes, so no domain test is needed. [Architecture 7.1](../Architecture.md#71-domain-driven-design) says search is a read-side query, not domain logic.
- **A second group for anonymous access.** The set endpoints share the prefix `/catalog/sets`. A second group with `AllowAnonymous()` keeps the admin group unchanged. The policy stays explicit, as [CLAUDE.md](../../CLAUDE.md) requires.
- **Query binding with `[AsParameters]`.** One request record holds all the query parameters, with defaults for paging and sorting.
- **Paging in SQL with a stable order.** `Skip` and `Take` run in the database. The order is the sort field, then the id. The id breaks ties, so a set does not show up on two pages.
- **One validation response shape.** Query validation returns the same `ProblemDetails` with `errors` as body validation. The mapping moves into a shared class.

```csharp
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Sets.Browse;

public static class BrowseSets
{
    public static void MapBrowseSets(this RouteGroupBuilder sets) =>
        sets.MapGet("/", Handle);

    private static async Task<Ok<PagedResponse<SetSummaryResponse>>> Handle(
        CatalogDbContext dbContext, CancellationToken cancellationToken)
    {
        var legoSets = await dbContext.LegoSets
            .Where(legoSet => legoSet.IsActive)
            .OrderBy(legoSet => legoSet.Name)
            .ToListAsync(cancellationToken);

        var items = legoSets
            .Select(legoSet => new SetSummaryResponse(
                legoSet.Id,
                legoSet.LegoSetNumber.Value,
                legoSet.Name,
                legoSet.PieceCount,
                legoSet.DailyPrice.Amount,
                legoSet.DailyPrice.Currency))
            .ToList();

        return TypedResults.Ok(new PagedResponse<SetSummaryResponse>(items, 1, items.Count, items.Count));
    }
}
```

```csharp
public sealed record BrowseSetsRequest(
```

Paging moves into the database. The handler counts the matches and skips and takes the rows of one page. Before this change it loaded every set. The order is by name and then by id, so pages do not repeat or skip sets.

Replace `src/Services/Catalog/BrickShare.Catalog.Api/Features/Sets/Browse/BrowseSets.cs` with this content:

```csharp
using System;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Domain;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Sets.Browse;

public static class BrowseSets
{
    public static void MapBrowseSets(this RouteGroupBuilder sets) =>
        sets.MapGet("/", Handle);

    private static async Task<Ok<PagedResponse<SetSummaryResponse>>> Handle(
        [AsParameters] BrowseSetsRequest request, CatalogDbContext dbContext, CancellationToken cancellationToken)
    {
        var matches = dbContext.LegoSets.Where(legoSet => legoSet.IsActive);

        var totalCount = await matches.CountAsync(cancellationToken);

        var rows = await matches
            .OrderBy(legoSet => legoSet.Name)
            .ThenBy(legoSet => legoSet.Id)
            .Skip((request.Page - 1) * request.PageSize)
            .Take(request.PageSize)
            .Select(legoSet => new SetRow(
                legoSet.Id,
                legoSet.LegoSetNumber,
                legoSet.Name,
                legoSet.PieceCount,
                legoSet.DailyPrice.Amount,
                legoSet.DailyPrice.Currency))
            .ToListAsync(cancellationToken);

        var items = rows
            .Select(row => new SetSummaryResponse(
                row.Id, row.LegoSetNumber.Value, row.Name, row.PieceCount, row.DailyPrice, row.Currency))
            .ToList();

        return TypedResults.Ok(new PagedResponse<SetSummaryResponse>(items, request.Page, request.PageSize, totalCount));
    }

    private sealed record SetRow(
        Guid Id, LegoSetNumber LegoSetNumber, string Name, int? PieceCount, long DailyPrice, string Currency);
}
```

`SetRow` holds the columns the list needs. The `LegoSetNumber` value object converts to its string in memory, the same way `InstanceView` reads it.

```csharp
using System.Linq;
using System.Text.Json;

using FluentValidation.Results;

using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;

namespace BrickShare.Catalog.Api.Infrastructure.Validation;

public static class ValidationProblems
{
    public static ValidationProblem From(ValidationResult result)
    {
        var errors = result.Errors
            .GroupBy(
                failure => JsonNamingPolicy.CamelCase.ConvertName(failure.PropertyName ?? string.Empty),
                failure => failure.ErrorMessage)
            .ToDictionary(group => group.Key, group => group.ToArray());

        return TypedResults.ValidationProblem(errors);
    }
}
```

`ValidationFilter` now calls the shared mapping. Replace `src/Services/Catalog/BrickShare.Catalog.Api/Infrastructure/Validation/ValidationFilter.cs` with this content. The only change is the last block: the error grouping moved to `ValidationProblems`.

```csharp
using System.Linq;
using System.Threading.Tasks;

using FluentValidation;

using Microsoft.AspNetCore.Http;
using Microsoft.Extensions.DependencyInjection;

namespace BrickShare.Catalog.Api.Infrastructure.Validation;

public sealed class ValidationFilter<T> : IEndpointFilter
{
    public async ValueTask<object?> InvokeAsync(EndpointFilterInvocationContext context, EndpointFilterDelegate next)
    {
        var request = context.Arguments.OfType<T>().FirstOrDefault();

        if (request is null)
        {
            return await next(context);
        }

        var validator = context.HttpContext.RequestServices.GetRequiredService<IValidator<T>>();
        var result = await validator.ValidateAsync(request, context.HttpContext.RequestAborted);

        if (result.IsValid)
        {
            return await next(context);
        }

        return ValidationProblems.From(result);
    }
}
```

The handler validates the request first. Replace `src/Services/Catalog/BrickShare.Catalog.Api/Features/Sets/Browse/BrowseSets.cs` with this content. The validator is injected like any other service, and the handler returns `ValidationProblem` on failure.

```csharp
using System;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Api.Infrastructure.Validation;
using BrickShare.Catalog.Domain;

using FluentValidation;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Sets.Browse;

public static class BrowseSets
{
    public static void MapBrowseSets(this RouteGroupBuilder sets) =>
        sets.MapGet("/", Handle);

    private static async Task<Results<Ok<PagedResponse<SetSummaryResponse>>, ValidationProblem>> Handle(
        [AsParameters] BrowseSetsRequest request,
        IValidator<BrowseSetsRequest> validator,
        CatalogDbContext dbContext,
        CancellationToken cancellationToken)
    {
        var validation = await validator.ValidateAsync(request, cancellationToken);

        if (!validation.IsValid)

            .Skip((request.Page - 1) * request.PageSize)
            .Take(request.PageSize)
            .Select(legoSet => new SetRow(
                legoSet.Id,
                legoSet.LegoSetNumber,
                legoSet.Name,
                legoSet.PieceCount,
                legoSet.DailyPrice.Amount,
                legoSet.DailyPrice.Currency))
            .ToListAsync(cancellationToken);

        var items = rows
            .Select(row => new SetSummaryResponse(
                row.Id, row.LegoSetNumber.Value, row.Name, row.PieceCount, row.DailyPrice, row.Currency))
            .ToList();

        return TypedResults.Ok(new PagedResponse<SetSummaryResponse>(items, request.Page, request.PageSize, totalCount));
    }

    private sealed record SetRow(
        Guid Id, LegoSetNumber LegoSetNumber, string Name, int? PieceCount, long DailyPrice, string Currency);
}
```

`src/Services/Catalog/BrickShare.Catalog.Api/Features/Sets/Details/GetSetDetails.cs` (replace the template class with this content)

```csharp
using System;
using System.Linq;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Sets.Details;

public static class GetSetDetails
{
    public static void MapGetSetDetails(this RouteGroupBuilder sets) =>
        sets.MapGet("/{id:guid}", Handle);

    private static async Task<Results<Ok<SetDetailsResponse>, ProblemHttpResult>> Handle(
        Guid id, CatalogDbContext dbContext, CancellationToken cancellationToken)
    {
        var legoSet = await dbContext.LegoSets.FirstOrDefaultAsync(
            candidate => candidate.Id == id, cancellationToken);

        if (legoSet is null)
        {
            return SetProblems.NotFound(id);
        }

        var themeName = await dbContext.Themes
            .Where(theme => theme.Id == legoSet.ThemeId)
            .Select(theme => theme.Name)
            .FirstOrDefaultAsync(cancellationToken);

        return TypedResults.Ok(new SetDetailsResponse(
            legoSet.Id,
            legoSet.LegoSetNumber.Value,
            legoSet.Name,
            legoSet.Year,
            legoSet.PieceCount,
            legoSet.MinifigureCount,
            themeName,
            legoSet.MinRentalDays.Days,
            legoSet.DailyPrice.Amount,
            legoSet.Deposit.Amount,
            legoSet.ReplacementValue.Amount,
            legoSet.LateFeePerDay.Amount,
            legoSet.DailyPrice.Currency));
    }
}

public sealed record SetDetailsResponse(
    Guid Id,
    string LegoSetNumber,
    string Name,
    int? Year,
    int? PieceCount,
    int? MinifigureCount,
    string? ThemeName,
    int MinRentalDays,
    long DailyPrice,
    long Deposit,
    long ReplacementValue,
    long LateFeePerDay,
    string Currency);
```
