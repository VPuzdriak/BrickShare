# Lesson 5.3. Bans in the `Customer` aggregate: ban, lift, automatic ban, test-first

Features: [F05](../features/05-customer-bans.md)
Previous: [5.2](5.2-profile-update-and-staff-customer-search.md) · Next: 5.4 Ban endpoints

## Summary

We add bans to the `Customer` aggregate. `AddBan` stores a ban and sets the customer status to `Banned`. `LiftBan` ends a ban, and the status returns to `Active` when no ban is left. `BanForLostSet` is the automatic ban from F05. The rules sit in the aggregate and return a `Result`. At the end the Domain tests are green and the Api tests still pass. The new members stay out of EF Core until lesson 5.4 stores bans.

## The problem

A customer cannot be banned yet. [F05](../features/05-customer-bans.md) names the rules:

- "A ban has a reason (`LateReturn`, `NonReturn`, `Neglect`, `NonPayment`, `Other`), a comment, who banned, from, until (null = permanent), and lifted at."
- "**Automatic ban:** `ReservationLost` bans the customer with reason `NonReturn`, `BannedBy = system`."

The Customer model in [Architecture 3.6](../Architecture.md#36-customer-service) adds two things: a `Ban` record for each ban, and a `Status` on the customer with the values `Active` and `Banned`.

The rules belong in the aggregate. [Architecture 7.1](../Architecture.md#71-domain-driven-design) and [CLAUDE.md](../../CLAUDE.md) say so: "Business rules live in aggregates and value objects, not in endpoints or handlers." Lesson 5.4 exposes the ban endpoints. Lesson 10.7 calls the automatic ban when a set is lost. Both need one tested method to call.

Concepts we introduce:

- **A child entity inside an aggregate.** `Ban` is an entity that only `Customer` creates and changes. It has no public setters. The lift method is `internal`, so only the domain assembly can change it.
- **A status that follows the bans.** `Status` is `Banned` while at least one ban is not lifted. One private method holds that rule, so the add and the lift methods cannot disagree.
- **The current time as a parameter.** The aggregate takes `now` from its caller. The handler in lesson 5.4 passes `timeProvider.GetUtcNow()`. The domain tests use `FakeTimeProvider` to set the time, as [CLAUDE.md](../../CLAUDE.md) requires for time-dependent tests.

Scope decisions for this lesson. F05 gives the fields and the automatic ban. The rest below are choices, not doc rules:

- **A comment is required.** F05 names a comment but gives no rule for a blank one. A ban with no comment gives staff nothing to read later.
- **A temporary ban must end after the current time.** A ban that ends in the past does nothing. The rule stops that mistake at the aggregate.
- **Lifting an unknown ban or a lifted ban fails.** Each failure returns its own error code. The API maps them in lesson 5.4.
- **The automatic ban is permanent and has a fixed comment.** F05 sets the reason and the actor. It does not set an end date, so the ban has none (`until: null`).
- **Temporary bans do not end by themselves.** F05 does not say how a temporary ban ends. This lesson stores `until` and does not expire bans. The open question is listed in the final report.
- **`BannedBy` is a string.** It holds the staff `oid` or the value `system`. Keeping it a string lets the automatic ban use the same field.
- **The aggregate creates the ban id.** The id is a `Guid.CreateVersion7()`. The lift method takes the id that the caller reads from `Bans`.
- **No events yet.** Domain events for bans come with module 7. This lesson stores no bans, so lesson 5.4 adds the database mapping and the migration.

```csharp
using AwesomeAssertions;

using Microsoft.Extensions.Time.Testing;
```

```csharp
using System;

using BrickShare.SharedKernel;

namespace BrickShare.Customers.Domain;

public sealed class Ban : Entity<Guid>
{
    public const string SystemActor = "system";

    internal Ban(Guid id, BanReason reason, string comment, string bannedBy, DateTimeOffset from, DateTimeOffset? until)
        : base(id)
    {
        Reason = reason;
        Comment = comment;
        BannedBy = bannedBy;
        From = from;
        Until = until;
    }

    public BanReason Reason { get; }

    public string Comment { get; }

    public string BannedBy { get; }

    public DateTimeOffset From { get; }

    public DateTimeOffset? Until { get; }

    public DateTimeOffset? LiftedAt { get; private set; }

    public bool IsActive => LiftedAt is null;

    internal void Lift(DateTimeOffset now) => LiftedAt = now;
}
```

```csharp
using System;
using System.Collections.Generic;

using BrickShare.SharedKernel;

namespace BrickShare.Customers.Domain;

public sealed class Customer : AggregateRoot<Guid>
{
    private const int MaxDisplayNameLength = 100;
    private const int MaxPhoneLength = 32;
    private const string LostSetComment = "The rented set was lost.";

    private static readonly DomainError DisplayNameRequired = new(
        "customer.display_name_required",
        "A display name is required.");

    private static readonly DomainError DisplayNameTooLong = new(
        "customer.display_name_too_long",
        "A display name has at most 100 characters.");

    private static readonly DomainError PhoneTooLong = new(
        "customer.phone_too_long",
        "A phone number has at most 32 characters.");

    private readonly List<Ban> _bans = [];

    private Customer()
        : this(Guid.Empty, string.Empty, string.Empty, default)
    {
    }

    public Customer(Guid id, string email, string displayName, DateTimeOffset createdAt)
        : base(id)
    {
        Email = email;
        DisplayName = displayName;
        CreatedAt = createdAt;
    }

    public string Email { get; private set; }

    public string DisplayName { get; private set; }

    public DateTimeOffset CreatedAt { get; private set; }

    public string? Phone { get; private set; }

    public CustomerStatus Status { get; private set; } = CustomerStatus.Active;

    public IReadOnlyList<Ban> Bans => _bans.AsReadOnly();

    public Result UpdateProfile(string? displayName, string? phone)
    {
        var name = displayName?.Trim() ?? string.Empty;
        var number = string.IsNullOrWhiteSpace(phone) ? null : phone.Trim();

        if (name.Length == 0)
        {
            return Result.Failure(DisplayNameRequired);
        }

        if (name.Length > MaxDisplayNameLength)
        {
            return Result.Failure(DisplayNameTooLong);
        }

        if (number?.Length > MaxPhoneLength)
        {
            return Result.Failure(PhoneTooLong);
        }

        DisplayName = name;
        Phone = number;

        return Result.Success();
    }

    public Result AddBan(BanReason reason, string? comment, string bannedBy, DateTimeOffset? until, DateTimeOffset now)
    {
        _bans.Add(new Ban(Guid.CreateVersion7(), reason, comment ?? string.Empty, bannedBy, now, until));
        Status = CustomerStatus.Banned;

        return Result.Success();
    }

    public Result LiftBan(Guid banId, DateTimeOffset now)
    {
        _bans.Find(candidate => candidate.Id == banId)?.Lift(now);

        return Result.Success();
    }

    public Result BanForLostSet(DateTimeOffset now) =>
        AddBan(BanReason.NonReturn, LostSetComment, Ban.SystemActor, until: null, now: now);
}
```
