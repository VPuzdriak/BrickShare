# Lesson 2.8c. `ISetSpecificationProvider` port and Rebrickable adapter: set, minifigures and theme tree, stub-based tests

Features: [F01](../features/01-catalog-management.md#lookup-in-rebrickable)
Previous: [2.8b](2.8b-set-number-lego-number-and-validation.md) · Next: [2.8d](2.8d-unknown-set-returns-null.md)

## Summary

We add the port `ISetSpecificationProvider` and the record `SetSpecification` to the domain. We add the adapter `RebrickableSetSpecificationProvider` in the Api project. It reads a set, its minifigures, and its theme tree from Rebrickable, and maps them to a `SetSpecification`. The test uses a stub HTTP handler, so no test calls Rebrickable. At the end one adapter test is green.

## The problem

[Architecture.md section 3.2](../Architecture.md#32-catalog-service) says the domain depends on the port, and a typed `HttpClient` implements it. The Rebrickable JSON stays out of the domain. A set's theme in Rebrickable can be nested, and lesson 2.7 gives us `RebrickableTheme.TopLevel`. The adapter must build the theme tree from Rebrickable's `parent_id` values.

[Catalog management](../features/01-catalog-management.md#lookup-in-rebrickable) lists the draft fields: name, year, piece count, minifigure count, top-level theme, image URL, and page URL.

```csharp
using System;
using System.Collections.Generic;
using System.Net;
using System.Net.Http;
using System.Text;
using System.Threading;
using System.Threading.Tasks;

namespace BrickShare.Catalog.Api.Tests;

public sealed class RebrickableStub : HttpMessageHandler
{
    private const string TitanicSet = """
        {
          "set_num": "10294-1",
          "name": "Titanic",
          "year": 2021,
          "theme_id": 1008,
          "num_parts": 9092,
          "set_img_url": "https://cdn.rebrickable.com/media/sets/10294-1.jpg",
          "set_url": "https://rebrickable.com/sets/10294-1/titanic/"
        }
        """;

    private const string TitanicMinifigs = """
        {
          "count": 3,
          "next": null,
          "previous": null,
          "results": []
        }
        """;

    private const string SubTheme = """
        {
          "id": 1008,
          "name": "Sub Theme",
          "parent_id": 158
        }
        """;

    private const string TopTheme = """
        {
          "id": 158,
          "name": "Top Theme",
          "parent_id": null
        }
        """;

    private readonly Dictionary<string, string> _responses = [];

    public List<string> RequestedPaths { get; } = [];

    public static RebrickableStub WithTitanic() => new RebrickableStub()
        .Respond("/api/v3/lego/sets/10294-1/", TitanicSet)
        .Respond("/api/v3/lego/sets/10294-1/minifigs/", TitanicMinifigs)
        .Respond("/api/v3/lego/themes/1008/", SubTheme)
        .Respond("/api/v3/lego/themes/158/", TopTheme);

    public RebrickableStub Respond(string path, string json)
    {
        _responses[path] = json;
        return this;
    }

    public HttpClient CreateClient() => new(this) { BaseAddress = new Uri("https://rebrickable.com/") };

    protected override Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        var path = request.RequestUri!.AbsolutePath;
        RequestedPaths.Add(path);

        var response = _responses.TryGetValue(path, out var json)
            ? new HttpResponseMessage(HttpStatusCode.OK) { Content = new StringContent(json, Encoding.UTF8, "application/json") }
            : new HttpResponseMessage(HttpStatusCode.NotFound);

        return Task.FromResult(response);
    }
}
```

## Step 4. Green: the adapter reads the set, the minifigures, and the theme tree

The adapter takes the `HttpClient` in its constructor. Each call reads JSON with the snake-case naming policy, because Rebrickable uses `set_num`, `num_parts`, and `parent_id`. A non-success status throws for now. Lesson 2.8d adds the `404` case.

We create the adapter file with the CLI. Run from the repository root:

```powershell

```

`src/Services/Catalog/BrickShare.Catalog.Api/Infrastructure/Rebrickable/RebrickableSetSpecificationProvider.cs` (replace the template class with this content)

```csharp
using System;
using System.Net.Http;
using System.Net.Http.Json;
using System.Text.Json;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Domain;

namespace BrickShare.Catalog.Api.Infrastructure.Rebrickable;

public sealed class RebrickableSetSpecificationProvider(HttpClient httpClient) : ISetSpecificationProvider
{
    private static readonly JsonSerializerOptions JsonOptions = new()
    {
        PropertyNamingPolicy = JsonNamingPolicy.SnakeCaseLower
    };

    public async Task<SetSpecification?> FindAsync(RebrickableSetNumber setNumber, CancellationToken cancellationToken)
    {
        var setResponse = await GetAsync<SetResponse>($"api/v3/lego/sets/{setNumber.Value}/", cancellationToken);
        var minifigs = await GetAsync<MinifigsResponse>($"api/v3/lego/sets/{setNumber.Value}/minifigs/", cancellationToken);
        var theme = await LoadThemeAsync(setResponse.ThemeId, cancellationToken);

        return new SetSpecification(
            setNumber,
            setResponse.Name,
            setResponse.Year,
            setResponse.NumParts,
            minifigs.Count,
            theme,
            setResponse.SetImgUrl is null ? null : new Uri(setResponse.SetImgUrl),
            new Uri(setResponse.SetUrl));
    }

    private async Task<RebrickableTheme> LoadThemeAsync(int themeId, CancellationToken cancellationToken)
    {
        var themeResponse = await GetAsync<ThemeResponse>($"api/v3/lego/themes/{themeId}/", cancellationToken);
        RebrickableTheme? parent = themeResponse.ParentId is int parentId
            ? await LoadThemeAsync(parentId, cancellationToken)
            : null;

        return new RebrickableTheme(themeResponse.Id, themeResponse.Name, parent);
    }

    private async Task<T> GetAsync<T>(string path, CancellationToken cancellationToken) where T : class
    {
        using var response = await httpClient.GetAsync(path, cancellationToken);
        response.EnsureSuccessStatusCode();

        return await response.Content.ReadFromJsonAsync<T>(JsonOptions, cancellationToken)
            ?? throw new HttpRequestException($"Rebrickable returned an empty body for {path}.");
    }

    private sealed record SetResponse(string Name, int? Year, int NumParts, int ThemeId, string? SetImgUrl, string SetUrl);

    private sealed record MinifigsResponse(int Count);

    private sealed record ThemeResponse(int Id, string Name, int? ParentId);
}
```

`LoadThemeAsync` calls itself for each parent, so a theme tree of any depth becomes a chain of `RebrickableTheme` records. `TopLevel` from lesson 2.7 gives the top of the chain. The private records hold only the fields the adapter reads. `System.Text.Json` ignores the rest.
