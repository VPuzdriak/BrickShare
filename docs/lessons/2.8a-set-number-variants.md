## Summary

We add the value object `RebrickableSetNumber`. It turns the number the admin types into the Rebrickable reference. `10294` becomes `10294-1`, and `10294-2` stays `10294-2`. At the end two domain tests are green. The input check and the LEGO set number come in lesson 2.8b.

## The problem

[Catalog management](../features/01-catalog-management.md#lookup-in-rebrickable) says:

> The admin enters a set identifier, for example `10294` or `10294-1`. Without a variant suffix, Catalog tries `-1`.

Nothing in the code does this yet. The rule is small, but the lookup depends on it. We introduce a value object, `RebrickableSetNumber`, in the Domain project. A value object keeps a rule in one place and gives it fast unit tests. The domain does not call Rebrickable. It only turns text into a Rebrickable reference.

`Parse` returns `Result<RebrickableSetNumber>`, the shared-kernel result type from lesson 1.6. This lesson only produces success. Lesson 2.8b adds the failure branch for invalid input without changing the signature.

```csharp
using BrickShare.SharedKernel;

namespace BrickShare.Catalog.Domain;

public sealed record RebrickableSetNumber
{
    private RebrickableSetNumber(string value)
    {
        Value = value;
    }

    public string Value { get; }

    public static Result<RebrickableSetNumber> Parse(string input) =>
        Result.Success(new RebrickableSetNumber(input + "-1"));
}
```

## Step 5. Green: add `-1` only when there is no variant

`Parse` checks for a dash. Without one, it appends the default variant. With one, it keeps the input.

`src/Services/Catalog/BrickShare.Catalog.Domain/RebrickableSetNumber.cs` (replace the `Parse` method with the constant and the new method)

Before:

```csharp
    public static Result<RebrickableSetNumber> Parse(string input) =>
        Result.Success(new RebrickableSetNumber(input + "-1"));
```

After:

```csharp
    private const string DefaultVariant = "-1";

    public static Result<RebrickableSetNumber> Parse(string input)
    {
        var value = input.Contains('-') ? input : input + DefaultVariant;

        return Result.Success(new RebrickableSetNumber(value));
    }
```

Run from the repository root:

```powershell
dotnet test --project tests/Services/Catalog/BrickShare.Catalog.Domain.Tests
```

Expected: green. Both `RebrickableSetNumberTests` pass.

No refactor step is needed. The method is short, and the rule sits in one place.
