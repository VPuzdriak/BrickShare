# Lesson 2.9. Submit a set from a Rebrickable draft, refresh specs

Features: [F01](../features/01-catalog-management.md#lookup-in-rebrickable)
Previous: [2.8j](2.8j-lookup-unavailable-503.md) · Next: 2.10 `InventoryCode` value object: alphabet, scramble, check character, parsing, test-first

## Summary

We let an admin save a set from a Rebrickable draft. The set keeps its Rebrickable reference, its Rebrickable facts, and the local theme it belongs to. We also add `POST /catalog/sets/{id}/refresh-specs`, which re-fetches the Rebrickable facts and leaves the shop fields alone. At the end the Domain and Api tests for both paths are green.

## The problem

[Catalog management](../features/01-catalog-management.md#lookup-in-rebrickable) describes the second half of the two-step flow. Lesson 2.8 returns a draft and saves nothing. Submit is the step that saves:

> On submit, Catalog generates the set id and stores the Rebrickable reference, the Rebrickable theme id, and the time of the lookup, so the data can be refreshed later.

The same section adds three more rules this lesson covers:

- A missing local theme is created on submit.
- If a set with the same Rebrickable reference already exists, the request returns `409` with the id of the existing set.
- **Refresh:** the admin re-fetches Rebrickable data for an existing set. Only Rebrickable fields are updated. Shop data (prices, deposit, age) stays unchanged.

Before this lesson the `LegoSet` has no link to Rebrickable and no theme. The `Theme` aggregate from lesson 2.7 exists in the domain, but nothing stores it. Three things follow:

- A set cannot be refreshed, because nothing remembers its Rebrickable reference.
- A set cannot point to its theme, because the `themes` table does not exist yet. Lesson 2.7 left both for this lesson.
- A duplicate submit would create a second set for the same Rebrickable set, because nothing checks the reference.

The concepts we introduce:

- **Aggregate methods for external facts.** `LegoSet.LinkToRebrickable` and `LegoSet.RefreshSpecification` take a `SetSpecification` from the port. They copy the Rebrickable facts and leave the rest of the set alone. The aggregate does not call Rebrickable. The handler calls the port and passes the result in.
- **Theme as its own aggregate.** A new theme is a separate aggregate, so it is saved in its own transaction before the set. CLAUDE.md allows one aggregate per transaction. A theme that is saved but never used is harmless, and the next submit reuses it.
- **Reference as text.** The aggregate stores the Rebrickable reference as a `string`, named `RebrickableSetNum` as in [Architecture.md section 3.2](../Architecture.md#32-catalog-service). The `RebrickableSetNumber` value object checks the input. The database and the duplicate check use the plain text, so EF Core translates the query without a value converter.

What this lesson does not do:

- It does not change the lookup. F01 also names a `409` on the lookup. This lesson returns the `409` on submit, because submit is the step that saves the reference.
- It does not check that the request's LEGO set number matches the draft. The admin sends both.
- It does not store the image URL or the Rebrickable page URL. The draft returns them, and no column holds them yet.
- It does not store sub-themes. The top-level theme is the catalog theme (`RebrickableTheme.TopLevel` from lesson 2.7).

```csharp
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Infrastructure.Persistence;

public sealed class ThemeConfiguration : IEntityTypeConfiguration<Theme>

        builder.Property(theme => theme.Id)

        builder.Ignore(theme => theme.DomainEvents);

}
```

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Domain;

using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Infrastructure.Persistence;

public static class ThemeCatalog
{
    public static async Task<Theme> GetOrCreateThemeAsync(
        this CatalogDbContext dbContext, RebrickableTheme topLevelTheme, CancellationToken cancellationToken)
    {
        var existing = await dbContext.Themes.FirstOrDefaultAsync(
            candidate => candidate.RebrickableThemeId == topLevelTheme.Id, cancellationToken);

        if (existing is not null)
        {
            return existing;
        }

        var theme = Theme.FromRebrickable(Guid.CreateVersion7(), topLevelTheme);

        dbContext.Themes.Add(theme);
        await dbContext.SaveChangesAsync(cancellationToken);

        return theme;
    }
}
```

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Api.Infrastructure.Validation;
using BrickShare.Catalog.Domain;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;
using Microsoft.EntityFrameworkCore;

namespace BrickShare.Catalog.Api.Features.Sets.Create;

public static class CreateSet
{
    public static void MapCreateSet(this RouteGroupBuilder sets) =>
        sets.MapPost("/", Handle).AddEndpointFilter<ValidationFilter<SetRequest>>();

    private static async Task<Results<Created<SetResponse>, ProblemHttpResult>> Handle(
        SetRequest request,
        CatalogDbContext dbContext,
        ISetSpecificationProvider specifications,
        TimeProvider timeProvider,
        CancellationToken cancellationToken)
    {
        if (request.RebrickableSetNumber is not null)
        {
            return await SubmitDraft(
                request, request.RebrickableSetNumber, dbContext, specifications, timeProvider, cancellationToken);
        }

        var legoSet = request.ToLegoSet(Guid.CreateVersion7());

        dbContext.LegoSets.Add(legoSet);
        await dbContext.SaveChangesAsync(cancellationToken);

        return TypedResults.Created($"/catalog/sets/{legoSet.Id}", SetResponse.From(legoSet));
    }

    private static async Task<Results<Created<SetResponse>, ProblemHttpResult>> SubmitDraft(
        SetRequest request,
        string rebrickableSetNumber,
        CatalogDbContext dbContext,
        ISetSpecificationProvider specifications,
        TimeProvider timeProvider,
        CancellationToken cancellationToken)
    {
        var parsed = RebrickableSetNumber.Parse(rebrickableSetNumber);

        if (parsed.IsFailure)
        {
            return SetProblems.InvalidSetNumber(rebrickableSetNumber);
        }

        var existing = await dbContext.LegoSets.FirstOrDefaultAsync(
            legoSet => legoSet.RebrickableSetNum == parsed.Value.Value, cancellationToken);

        if (existing is not null)
        {
            return SetProblems.RebrickableSetAlreadyExists(existing.Id);
        }

        SetSpecification? specification;

        try
        {
            specification = await specifications.FindAsync(parsed.Value, cancellationToken);
        }
        catch (SetSpecificationUnavailableException)
        {
            return SetProblems.RebrickableUnavailable();
        }

        if (specification is null)
        {
            return SetProblems.UnknownSetNumber(rebrickableSetNumber);
        }

        var theme = await dbContext.GetOrCreateThemeAsync(specification.Theme.TopLevel, cancellationToken);

        var legoSet = request.ToLegoSet(Guid.CreateVersion7());
        legoSet.LinkToRebrickable(specification, theme.Id, timeProvider.GetUtcNow());

        dbContext.LegoSets.Add(legoSet);
        await dbContext.SaveChangesAsync(cancellationToken);

        return TypedResults.Created($"/catalog/sets/{legoSet.Id}", SetResponse.From(legoSet));
    }
}
```

```csharp
using System;
using System.Threading;
using System.Threading.Tasks;

using BrickShare.Catalog.Api.Infrastructure.Persistence;
using BrickShare.Catalog.Domain;

using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Http.HttpResults;
using Microsoft.AspNetCore.Routing;

namespace BrickShare.Catalog.Api.Features.Sets.RefreshSpecs;

public static class RefreshSetSpecs
{
    public static void MapRefreshSetSpecs(this RouteGroupBuilder sets) =>
        sets.MapPost("/{id:guid}/refresh-specs", Handle);

    private static async Task<Results<Ok<SetResponse>, ProblemHttpResult>> Handle(
        Guid id,
        CatalogDbContext dbContext,
        ISetSpecificationProvider specifications,
        TimeProvider timeProvider,
        CancellationToken cancellationToken)
    {
        var legoSet = await dbContext.LegoSets.FindAsync([id], cancellationToken);

        if (legoSet is null)
        {
            return SetProblems.NotFound(id);
        }

        if (legoSet.RebrickableSetNum is null)
        {
            return SetProblems.NoRebrickableReference(id);
        }

        var setNumber = RebrickableSetNumber.Parse(legoSet.RebrickableSetNum).Value;
        SetSpecification? specification;

        try
        {
            specification = await specifications.FindAsync(setNumber, cancellationToken);
        }
        catch (SetSpecificationUnavailableException)
        {
            return SetProblems.RebrickableUnavailable();
        }

        if (specification is null)
        {
            return SetProblems.UnknownSetNumber(setNumber.Value);
        }

        var theme = await dbContext.GetOrCreateThemeAsync(specification.Theme.TopLevel, cancellationToken);

        legoSet.RefreshSpecification(specification, theme.Id, timeProvider.GetUtcNow());
        await dbContext.SaveChangesAsync(cancellationToken);

        return TypedResults.Ok(SetResponse.From(legoSet));
    }
}
```
