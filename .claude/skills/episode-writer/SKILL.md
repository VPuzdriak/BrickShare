- Create a script in the .md file with the code samples.
- Estimate the episode as 10-15 mins. If you see that it might take longer, mention it explicitly and suggest to split it into multiple episodes.
- Don't create or change any code files in the project. User will copy the samples manually into the code files.
- Each sample should include the location of the code file it belongs to. It should include the anchor or context within the file where the code should be placed.
- Update the existing .md files if the reference to this new episode has to be present.
